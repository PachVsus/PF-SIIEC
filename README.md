# PF-SIIEC

Proyecto final de Infraestructura del Desarrollo Continuo: **Sistema de inventario con integración y entrega continua**.

## Propuesta

Aplicación de inventario con Flask y PostgreSQL, pruebas automatizadas, Docker Compose y un pipeline de GitHub Actions para validar cambios, publicar imágenes versionadas y desplegar en Linux.

## Estado

Propuesta y planificación. La implementación está pendiente. El tablero incluye 13 tareas distribuidas en cuatro semanas sugeridas, con dependencias y criterios de aceptación. Fechas y responsables por definir.
